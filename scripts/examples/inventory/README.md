# Inventory format for `check-names.mjs`

A plain JSON description of the frontend modules to check. Every field is optional except `modules[].name` and element `name`s. Build it from the Service Studio MCP read tools (`getScreen`, `getWebBlock`, `getDataModel`, `listApps`), from a Model API read-only probe, or by hand for a review.

```jsonc
{
  "style": "ConceptThing",            // or "Concept_Thing"; CLI --style pascal|underscore overrides; inferred if absent
  "handlers": "trigger-event",        // or "on-prefix" (Synobsys OnSave); CLI --handlers overrides
  "blockSuffix": false,               // true = reusable blocks end in "Block" (Synobsys); CLI --block-suffix
  "modules": [{
    "name": "Request_CW",
    "layer": "CW",                    // FrontEnd | CW | MCW | ... (FrontEnd enables BLK-08)
    "uiFlows": [{
      "name": "Requests",
      "screens": [{
        "name": "RequestList",
        "title": "Requests",          // missing → A11Y-08
        "roles": ["RequestViewer"],   // Anonymous/Registered → SEC-07 unless "publicIntended": true
        "isPopup": false,
        "inputParameters": [{ "name": "Status", "type": "Text", "mandatory": false }],
        "localVariables":  [{ "name": "IsLoading", "type": "Boolean" }],
        "dataSources":     [{ "name": "GetRequests", "kind": "aggregate|dataAction", "fetch": "AtStart|OnDemand", "inputs": ["Status"], "onAfterFetch": "GetRequestsOnAfterFetch" }],
        "actions":         [{ "name": "SearchOnClick",
                              "serverCalls": ["Request_Search"],      // >1 → CLG-01
                              "entityActions": [],                    // any → FSC-06
                              "localStorage": false,                  // true in OnInitialize → LCY-01
                              "assignsData": false, "guarded": false, // OnRender assigning unguarded → LCY-03
                              "refreshes": ["GetRequests"] }],        // own data source in its On After Fetch → LCY-07
        "lifecycle":       { "OnInitialize": "InitDefaults", "OnRender": "…" },   // event → action name; server calls there → FET-01
        "isSplash": false,                    // true + data sources → MOB-06
      }],
      "blocks": [{
        "name": "RequestCard",
        "public": true,
        "description": "Shows one request…",  // public without description → STR-03
        "insideList": false,                   // true + data sources → BLK-05
        "inputParameters": [], "localVariables": [], "dataSources": [], "actions": [],
        "events": [{ "name": "OnSelected", "parameters": [{ "name": "RequestId", "type": "Request Identifier" }] }]
      }]
    }],
    "clientActions":   [{ "name": "ShowFeedback", "public": true, "description": "…", "folder": "UIHelpers" }],
    "clientVariables": [{ "name": "RequestListPageSize", "type": "Integer" }]
  }]
}
```

Suppress a rule on an element with a reason: `"ignore": ["NAM-02: generated by the Forge component, can't rename"]`.

Files here:
- `good-request-cw.json`: a CW module that passes.
- `bad-request-portal.json`: a Front-End module with typical problems (default names, sensitive client variable, record parameters, screen data sources).
